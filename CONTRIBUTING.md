# Contributing to REDGRID

Thank you for your interest in contributing to REDGRID.

## Getting Started

1. Fork or clone the repository.
2. Install the required dependencies.
3. Configure the required environment variables.
4. Run the project locally.
5. Test your changes before submitting them.

## Development Guidelines

- Keep changes focused and related to the issue being addressed.
- Follow the existing project structure and coding conventions.
- Do not commit API keys, passwords, database credentials, JWT secrets, or other sensitive information.
- Validate changes on both frontend and backend where applicable.
- Test authentication and role-based access before submitting changes.

## Pull Requests

A pull request should include:

- A clear description of the changes
- The reason for the changes
- Relevant testing information
- Screenshots when UI changes are involved

## Security

Do not publicly disclose security vulnerabilities through normal issues.

Please follow the process described in `SECURITY.md`.

## Code Quality

Contributors should maintain readable, maintainable, and documented code.

All contributions should respect the project's open-source license and applicable third-party licenses.
